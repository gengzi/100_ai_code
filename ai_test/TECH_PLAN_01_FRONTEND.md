# 技术方案 01：前端开放平台与接口联调（仅前端）

说明：本方案基于 `REQUIREMENT_01_PLATFORM.md`，仅覆盖前端实现与交付形态，不包含后端服务。

## 1. 目标与交付形态
- 目标：提供可视化接口配置与流程编排（workflow 体验），支持测试与联调执行，并可一键导出流程定义。
- 交付形态：前端静态应用（SPA），离线或内网部署均可。
- 执行方式：前端直连执行（浏览器发起请求），无需后端调度。

## 2. 设计模式
- 配置驱动：全部由 schema 驱动 UI 与流程定义。
- 组件化：画布、节点、属性面板、执行与导出模块解耦。
- 可扩展：节点库与表单 schema 可增量扩展。
- 开源优先：画布与流程编排使用开源组件实现，减少自研成本。

## 3. 架构设计
- 页面层（pages/）
  - 流程列表页：流程创建、切换、删除
  - 编排工作台：画布 + 属性面板 + 执行 + 导出
- 功能层（features/）
  - canvas：基于 AntV X6 的节点编排画布
  - node-library：节点类型注册与展示
  - property-panel：节点属性编辑（含全局变量与响应映射）
  - flow-runner：测试与联调执行
  - flow-export：导入导出
- 通用层（components/、hooks/、utils/、types/）
  - 画布基础能力、表单组件、通用类型与校验

## 4. 流程与数据模型
- 流程定义 Flow
  - id、name、description
  - nodes: Node[]
  - edges: Edge[]
  - variables: 全局环境变量（贯穿整个流程）
  - globalHeaders: 全局请求头
  - globalParams: 全局请求参数
  - runConfig: 执行模式、超时与重试配置
- 节点定义 Node（支持多种类型）
  - http：接口请求
  - condition：条件分支
  - parallel / merge：并行与汇聚网关
  - subflow：子流程引用
  - group / lane：分组与泳道容器
- 节点配置
  - http.config：请求地址、方法、headers、body、auth、断言、响应映射
  - condition.config：表达式
  - subflow.config：流程引用
  - group/lane.config：尺寸、颜色
- 连线 Edge
  - source、target
  - condition: success / failure

## 5. 关键模块实现细节
### 5.1 可视化编排画布（AntV X6）
- 使用 AntV X6 提供节点式编排、连线、缩放与选择能力。
- 支持容器节点（group/lane）与子节点归属。
- 节点位置、连线关系实时保存到 Flow 数据模型。

### 5.2 节点库与注册机制
- 节点类型以 registry 形式注册。
- 每种节点有：组件、schema、默认配置。

### 5.3 属性面板与映射
- 基于 schema 渲染表单。
- 支持全局变量、全局 headers、全局 params 编辑。
- 支持节点响应映射，将上一个接口响应写入全局变量供后续使用。
- 子流程节点可选择其他流程作为引用。

### 5.4 测试与联调执行
- 执行引擎在浏览器内按 edges 顺序或条件驱动。
- 运行期维护“全局变量上下文”，用于请求参数替换与跨节点传递。
- 支持执行模式：单步、全量、成功场景、失败场景。
- 每个节点执行产出日志、耗时、响应与断言结果。
- 支持基础重试与超时配置。

### 5.5 Workflow 扩展能力
- 并行分支：并行网关触发多条分支执行。
- 条件表达式：条件节点控制 success/failure 分支。
- 子流程：子流程节点可复用已配置流程。
- 节点分组：容器节点可收纳子节点。
- 泳道：按角色/系统分区展示节点。

### 5.6 一键导出
- 导出 Flow JSON 文件（版本化）。
- 可选择导出为 zip（包含 flow.json + 元数据）。
- 导出时进行 schema 校验与提示。

### 5.7 开源组件清单（建议）
- 画布/编排：@antv/x6
- 表单：react-hook-form + zod（可选）
- JSON 编辑：@uiw/react-textarea-code-editor（可选）
- UI 组件库：Ant Design（如需快速落地）

## 6. 状态管理策略
- 流程列表 + 当前流程作为单一数据源。
- 选中节点、拖拽状态在局部状态管理。
- 导出与执行前进行完整校验，避免无效流程。

## 7. 前端数据存储
- localStorage 保存流程列表与当前流程。
- 支持 JSON 导入导出。

## 8. UI 与交互要点
- 清晰画布网格与节点对齐辅助线。
- 节点的成功/失败分支视觉差异化。
- 属性面板与画布联动高亮。
- 执行时节点高亮与状态流转可视化。

## 9. 可扩展性方案
- 节点 registry 支持动态注册。
- schema 支持新增字段类型（如 code editor、json editor）。
- Flow 版本字段支持未来迁移。

## 10. 风险与限制
- 前端执行受浏览器 CORS 限制，需要目标接口允许跨域或使用代理方案。
- 大规模并发执行存在浏览器性能上限。
- 复杂流程（循环、并行）后续可扩展。

## 11. 里程碑建议
1. 基础画布 + 节点拖拽 + 属性面板
2. 执行引擎 + 结果面板 + 日志
3. 响应映射 + 全局变量 + 流程列表管理
4. 高级 workflow（并行、条件、子流程、分组、泳道）
