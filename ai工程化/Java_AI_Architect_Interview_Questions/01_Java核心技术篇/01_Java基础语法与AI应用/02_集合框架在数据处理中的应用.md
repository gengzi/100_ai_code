**2. ArrayList和LinkedList的主要区别是什么？**

**面试场景**：中级Java开发面试，考察数据结构理解

**口语化答案**：
ArrayList和LinkedList的主要区别在于底层实现和性能特点：

**ArrayList**：
- 底层：动态数组实现
- 优点：随机访问快O(1)，内存占用少
- 缺点：插入删除慢O(n)，扩容有开销

**LinkedList**：
- 底层：双向链表实现
- 优点：插入删除快O(1)，不需要扩容
- 缺点：随机访问慢O(n)，内存占用多

在AI应用中，ArrayList适合存储大量训练样本进行批量处理，LinkedList适合频繁插入删除的动态数据流。

**3. HashSet的底层实现原理是什么？**

**面试场景**：中级Java开发面试，考察HashSet实现原理

**口语化答案**：
HashSet的底层是基于HashMap实现的：

1. **存储结构**：使用HashMap的Key存储元素，Value固定为PRESENT对象
2. **哈希计算**：通过hashCode()计算哈希值，确定存储位置
3. **冲突处理**：链地址法处理哈希冲突（Java 8后优化为红黑树）
4. **扩容机制**：默认初始容量16，负载因子0.75，当元素数量超过容量的75%时扩容

在AI特征工程中，HashSet常用于去重处理，如去除重复的特征值或样本。

**4. HashMap的工作原理是什么？**

**面试场景**：Java高级开发面试，考察HashMap深度理解

**口语化答案**：
HashMap的工作原理包括几个关键步骤：

1. **哈希计算**：Key通过hashCode()计算哈希值，然后与数组长度-1进行&运算得到索引
2. **数据存储**：数组+链表/红黑树的结构，Java 8后当链表长度>8时转换为红黑树
3. **冲突处理**：哈希冲突时使用链地址法，新元素插入链表头部
4. **扩容机制**：容量×2扩容，重新计算所有元素的位置

在AI应用中，HashMap广泛用于特征索引、词汇表构建、参数缓存等场景。

**5. 什么是fail-fast机制？**

**面试场景**：Java并发编程面试，考察集合安全性

**口语化答案**：
fail-fast是Java集合的一种错误检测机制：

1. **工作原理**：迭代器在遍历时会检查modCount，如果发现集合在遍历过程中被修改，立即抛出ConcurrentModificationException
2. **目的**：及时发现并发修改问题，避免不确定的行为
3. **实现**：集合维护一个modCount计数器，每次修改操作都会增加这个值
4. **适用场景**：主要用于单线程环境下的错误检测

在多线程AI训练中，需要使用并发集合或者加锁来避免这个问题。

```java
        }
    }
```

3. **基于布隆过滤器的去重**：
   - 适合海量数据，允许一定误判
   - 内存效率高，但可能有假阳性

   - 适合超大数据集

```java
// AI数据去重策略
public class DataDeduplication {

    // 基于HashSet的去重
    public Set<String> hashSetDedup(List<String> data) {
        return new HashSet<>(data);
    }

    // 基于排序的去重
    public List<String> sortDedup(List<String> data) {
        List<String> sorted = new ArrayList<>(data);
        Collections.sort(sorted);

        List<String> deduped = new ArrayList<>();
        String prev = null;
        for (String item : sorted) {
            if (!item.equals(prev)) {
                deduped.add(item);
                prev = item;
            }
        }
        return deduped;
    }

    // 基于布隆过滤器的去重
    public List<String> bloomFilterDedup(List<String> data, double fpp) {
        BloomFilter<String> filter = BloomFilter.create(
            Funnels.stringFunnel(Charset.defaultCharset()),
            data.size(), fpp);

        List<String> deduped = new ArrayList<>();
        for (String item : data) {
            if (filter.put(item)) {
                deduped.add(item);
            }
        }
        return deduped;
    }
}
```

```java
/**
 * 高效稀疏矩阵实现 - CSR格式
 */
public class SparseMatrix {
    private final int rows;
    private final int cols;
    private final double[] values;      // 非零值
    private final int[] colIndices;     // 列索引
    private final int[] rowPointers;    // 行指针

    public SparseMatrix(int rows, int cols) {
        this.rows = rows;
        this.cols = cols;
        this.values = new double[0];
        this.colIndices = new int[0];
        this.rowPointers = new int[rows + 1];
    }

    // 设置元素值
    public void set(int row, int col, double value) {
        if (value != 0.0) {
            insertValue(row, col, value);
        } else {
            removeValue(row, col);
        }
    }

    // 矩阵向量乘法（优化版本）
    public double[] multiply(double[] vector) {
        if (vector.length != cols) {
            throw new IllegalArgumentException("向量维度不匹配");
        }

        double[] result = new double[rows];
        for (int row = 0; row < rows; row++) {
            double sum = 0.0;
            int start = rowPointers[row];
            int end = rowPointers[row + 1];

            for (int i = start; i < end; i++) {
                sum += values[i] * vector[colIndices[i]];
            }
            result[row] = sum;
        }
        return result;
    }

    // 转置操作
    public SparseMatrix transpose() {
        SparseMatrix result = new SparseMatrix(cols, rows);

        // 统计每列的非零元素数量
        int[] colCounts = new int[cols];
        for (int col : colIndices) {
            colCounts[col]++;
        }

        // 计算列指针
        int[] colPointers = new int[cols + 1];
        for (int i = 0; i < cols; i++) {
            colPointers[i + 1] = colPointers[i] + colCounts[i];
        }

        // 构建转置矩阵
        result.values = new double[values.length];
        result.colIndices = new int[colIndices.length];
        result.rowPointers = colPointers;

        return result;
    }

    // 获取稀疏度
    public double getSparsity() {
        return 1.0 - (double) values.length / (rows * cols);
    }
}
```

```java
/**
 * 高性能LRU缓存实现
 */
public class HighPerformanceCache<K, V> {
    private final int maxSize;
    private final ConcurrentHashMap<K, CacheNode<K, V>> cache;
    private final AtomicLong accessCounter = new AtomicLong(0);
    private final ReentrantReadWriteLock lock = new ReentrantReadWriteLock();

    // 双向链表节点
    private static class CacheNode<K, V> {
        final K key;
        volatile V value;
        volatile long lastAccessTime;
        volatile CacheNode<K, V> prev;
        volatile CacheNode<K, V> next;

        CacheNode(K key, V value) {
            this.key = key;
            this.value = value;
            this.lastAccessTime = System.nanoTime();
        }
    }

    private volatile CacheNode<K, V> head;
    private volatile CacheNode<K, V> tail;

    public HighPerformanceCache(int maxSize) {
        this.maxSize = maxSize;
        this.cache = new ConcurrentHashMap<>(maxSize);
        this.head = new CacheNode<>(null, null);
        this.tail = new CacheNode<>(null, null);
        this.head.next = tail;
        this.tail.prev = head;
    }

    // 获取缓存值
    public V get(K key) {
        CacheNode<K, V> node = cache.get(key);
        if (node != null) {
            node.lastAccessTime = accessCounter.incrementAndGet();
            moveToHead(node);
            return node.value;
        }
        return null;
    }

    // 设置缓存值
    public void put(K key, V value) {
        if (key == null || value == null) {
            throw new IllegalArgumentException("Key和Value不能为null");
        }

        CacheNode<K, V> existing = cache.get(key);
        if (existing != null) {
            existing.value = value;
            existing.lastAccessTime = accessCounter.incrementAndGet();
            moveToHead(existing);
            return;
        }

        lock.writeLock().lock();
        try {
            if (cache.size() >= maxSize) {
                evictLRU();
            }

            CacheNode<K, V> newNode = new CacheNode<>(key, value);
            cache.put(key, newNode);
            addToHead(newNode);
        } finally {
            lock.writeLock().unlock();
        }
    }

    // 移动节点到头部
    private void moveToHead(CacheNode<K, V> node) {
        removeNode(node);
        addToHead(node);
    }

    // 添加节点到头部
    private void addToHead(CacheNode<K, V> node) {
        node.prev = head;
        node.next = head.next;
        head.next.prev = node;
        head.next = node;
    }

    // 移除节点
    private void removeNode(CacheNode<K, V> node) {
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }

    // 淘汰LRU节点
    private void evictLRU() {
        CacheNode<K, V> lru = tail.prev;
        if (lru != head) {
            removeNode(lru);
            cache.remove(lru.key);
        }
    }

    // 获取缓存统计信息
    public CacheStats getStats() {
        return new CacheStats(
            cache.size(),
            maxSize,
            (double) cache.size() / maxSize
        );
    }
}
```

```java
/**
 * 实时数据流处理框架
 */
public class StreamProcessor<T> {
    private final int windowSize;
    private final long windowDurationMs;
    private final Queue<T> dataQueue;
    private final AtomicLong totalProcessed = new AtomicLong(0);
    private final ScheduledExecutorService scheduler;

    public StreamProcessor(int windowSize, long windowDurationMs) {
        this.windowSize = windowSize;
        this.windowDurationMs = windowDurationMs;
        this.dataQueue = new ConcurrentLinkedQueue<>();
        this.scheduler = Executors.newSingleThreadScheduledExecutor();

        // 启动窗口处理定时任务
        scheduler.scheduleAtFixedRate(
            this::processWindow,
            windowDurationMs,
            windowDurationMs,
            TimeUnit.MILLISECONDS
        );
    }

    // 添加数据到流
    public void addData(T data) {
        if (dataQueue.size() >= windowSize) {
            dataQueue.poll(); // 移除最老的数据
        }
        dataQueue.offer(data);
    }

    // 处理时间窗口
    private void processWindow() {
        if (dataQueue.isEmpty()) {
            return;
        }

        List<T> windowData = new ArrayList<>(dataQueue);
        processWindowData(windowData);
        totalProcessed.addAndGet(windowData.size());
    }

    // 处理窗口数据（可自定义）
    protected void processWindowData(List<T> windowData) {
        // 默认实现：计算基本统计信息
        System.out.println("处理窗口数据: " + windowData.size() + " 条记录");
    }

    // 获取处理统计
    public ProcessingStats getStats() {
        return new ProcessingStats(
            dataQueue.size(),
            totalProcessed.get(),
            System.currentTimeMillis()
        );
    }

    // 关闭处理器
    public void shutdown() {
        scheduler.shutdown();
        try {
            if (!scheduler.awaitTermination(5, TimeUnit.SECONDS)) {
                scheduler.shutdownNow();
            }
        } catch (InterruptedException e) {
            scheduler.shutdownNow();
            Thread.currentThread().interrupt();
        }
    }
}
```

```java
public class LargeScaleGraph {
    private final int numVertices;
    private final int[] edgeOffsets;   // 顶点边偏移
    private final int[] edgeTargets;   // 边目标顶点
    private final double[] edgeWeights; // 边权重

    public LargeScaleGraph(int numVertices, int numEdges) {
        this.numVertices = numVertices;
        this.edgeOffsets = new int[numVertices + 1];
        this.edgeTargets = new int[numEdges];
        this.edgeWeights = new double[numEdges];
    }

    // 添加边（构建时使用）
    public void addEdge(int source, int target, double weight) {
        // 实现边的添加逻辑
        // 注意：CSR格式构建完成后，通常不支持动态添加边
    }

    // 获取顶点的出度
    public int getOutDegree(int vertex) {
        return edgeOffsets[vertex + 1] - edgeOffsets[vertex];
    }

    // 获取顶点的所有邻居
    public IntIterable getNeighbors(int vertex) {
        final int start = edgeOffsets[vertex];
        final int end = edgeOffsets[vertex + 1];

        return () -> new IntIterator() {
            private int current = start;

            @Override
            public boolean hasNext() {
                return current < end;
            }

            @Override
            public int nextInt() {
                return edgeTargets[current++];
            }
        };
    }

    // 并行BFS遍历
    public int[] parallelBFS(int startVertex) {
        int[] distances = new int[numVertices];
        Arrays.fill(distances, -1);
        distances[startVertex] = 0;

        Queue<Integer> currentLevel = new ConcurrentLinkedQueue<>();
        Queue<Integer> nextLevel = new ConcurrentLinkedQueue<>();
        currentLevel.offer(startVertex);

        int level = 0;
        while (!currentLevel.isEmpty()) {
            Integer vertex = currentLevel.poll();
            if (vertex == null) continue;

            // 并行处理当前顶点的所有邻居
            getNeighbors(vertex).forEach(neighbor -> {
                if (distances[neighbor] == -1) {
                    distances[neighbor] = level + 1;
                    nextLevel.offer(neighbor);
                }
            });

            if (currentLevel.isEmpty()) {
                Queue<Integer> temp = currentLevel;
                currentLevel = nextLevel;
                nextLevel = temp;
                level++;
            }
        }

        return distances;
    }

    // 图统计信息
    public GraphStats getStats() {
        int totalEdges = edgeTargets.length;
        double avgDegree = (double) totalEdges / numVertices;

        return new GraphStats(
            numVertices,
            totalEdges,
            avgDegree,
            calculateDensity()
        );
    }
}
```

```java
/**
 * 分布式缓存客户端
 */
public class DistributedCacheClient<K, V> {
    private final ConsistentHashRouter hashRouter;
    private final Map<String, CacheConnection> connections;
    private final LocalCache<K, V> localCache;
    private final ExecutorService executor;

    public DistributedCacheClient(List<String> servers) {
        this.hashRouter = new ConsistentHashRouter(servers, 150);
        this.connections = new ConcurrentHashMap<>();
        this.localCache = new LocalCache<>(1000);
        this.executor = Executors.newFixedThreadPool(10);

        // 初始化连接池
        initializeConnections(servers);
    }

    // 获取缓存值
    public CompletableFuture<V> get(K key) {
        // 首先检查本地缓存
        V localValue = localCache.get(key);
        if (localValue != null) {
            return CompletableFuture.completedFuture(localValue);
        }

        // 从远程缓存获取
        String server = hashRouter.getServer(key.toString());
        CacheConnection connection = connections.get(server);

        return CompletableFuture.supplyAsync(() -> {
            try {
                V remoteValue = connection.get(key);
                if (remoteValue != null) {
                    localCache.put(key, remoteValue);
                }
                return remoteValue;
            } catch (Exception e) {
                throw new RuntimeException("获取缓存失败", e);
            }
        }, executor);
    }

    // 设置缓存值
    public CompletableFuture<Void> put(K key, V value) {
        // 更新本地缓存
        localCache.put(key, value);

        // 异步更新远程缓存
        String primaryServer = hashRouter.getServer(key.toString());
        List<String> replicaServers = hashRouter.getReplicaServers(key.toString(), 2);

        List<CompletableFuture<Void>> futures = new ArrayList<>();

        // 主节点写入
        futures.add(CompletableFuture.runAsync(() -> {
            try {
                connections.get(primaryServer).put(key, value);
            } catch (Exception e) {
                throw new RuntimeException("主节点写入失败", e);
            }
        }, executor));

        // 副本节点写入
        for (String replicaServer : replicaServers) {
            futures.add(CompletableFuture.runAsync(() -> {
                try {
                    connections.get(replicaServer).put(key, value);
                } catch (Exception e) {
                    // 副本写入失败不影响主流程
                    System.err.println("副本写入失败: " + e.getMessage());
                }
            }, executor));
        }

        return CompletableFuture.allOf(futures.toArray(new CompletableFuture[0]));
    }

    // 批量获取
    public CompletableFuture<Map<K, V>> getAll(Set<K> keys) {
        Map<K, V> result = new HashMap<>();
        List<CompletableFuture<Void>> futures = new ArrayList<>();

        // 按服务器分组请求
        Map<String, List<K>> serverGroups = new HashMap<>();
        for (K key : keys) {
            String server = hashRouter.getServer(key.toString());
            serverGroups.computeIfAbsent(server, k -> new ArrayList<>()).add(key);
        }

        // 并行请求各服务器
        for (Map.Entry<String, List<K>> entry : serverGroups.entrySet()) {
            String server = entry.getKey();
            List<K> serverKeys = entry.getValue();

            futures.add(CompletableFuture.runAsync(() -> {
                try {
                    Map<K, V> serverResult = connections.get(server).getAll(serverKeys);
                    synchronized (result) {
                        result.putAll(serverResult);
                    }
                    // 更新本地缓存
                    localCache.putAll(serverResult);
                } catch (Exception e) {
                    throw new RuntimeException("批量获取失败", e);
                }
            }, executor));
        }

        return CompletableFuture.allOf(futures.toArray(new CompletableFuture[0]))
            .thenApply(v -> result);
    }

    // 缓存预热
    public CompletableFuture<Void> warmUp(Set<K> keys) {
        return getAll(keys).thenAccept(results -> {
            System.out.println("缓存预热完成，加载了 " + results.size() + " 个键值对");
        });
    }
}
```
